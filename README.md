# Virtuální dopravní hřiště (VR)

Repozitář pro ročníkovou práci zaměřenou na vývoj výukové VR hry v enginu Unity. Cílem projektu je bezpečně naučit uživatele pravidla silničního provozu ve virtuální realitě.

## 🎮 O projektu
- **Žánr:** Výuková simulace / VR hra
- **Engine:** Unity (C#)

## ✨ Hlavní funkce
- Interaktivní křižovatky a semafory
- Výuka dopravních značek a přednosti v jízdě
